# Student reflection guide — use your actual observations

This file is an evidence scaffold, not a fabricated account of work done personally by a student.

1. **Purpose:** Explain how the website helps Australian teenagers recognise cyberbullying, respond safely and get support.
2. **Audience:** Identify how the writing, photography, examples and interface were designed for secondary students.
3. **Multimodality:** Identify linguistic, visual, gestural, spatial and aural modes and describe one way each contributes to meaning.
4. **Strongest design choice:** Discuss the interaction between the bystander buttons, the network, and explanatory copy.
5. **Evidence:** Explain how source dates and chart labels keep eSafety statistics accurate.
6. **Design challenge:** Report a real issue found when testing, such as a small-screen overlap or inaccessible focus, and the actual change made.
7. **Ethics:** Discuss why the website uses fictional scenarios rather than accounts from named classmates.
8. **Future improvements:** Include genuinely useful ideas such as translation, reviewed feedback from peers and improved assistive-device testing.

Do not describe tasks you did not perform. Personalise the reflection after reviewing the website and doing the classroom tests.
