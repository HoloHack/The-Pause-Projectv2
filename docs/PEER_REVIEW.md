# Structured student peer review (three sessions)

Ask each reviewer, without coaching them through the interface:

1. What three features help identify bullying?
2. How might forwarding a harmful message affect its reach?
3. Name two safer bystander actions.
4. Where would you go if you needed help with cyberbullying?
5. Did any chart, diagram or animation make the explanation clearer? Which one?
6. Could you navigate the full website and use its controls easily?
7. What confused you or felt unnecessary?

Record actual reviewer observations, device, date and changes made. Do not invent scores or testimonial quotations. If possible, test one narrow-screen device and one keyboard-only pass.
