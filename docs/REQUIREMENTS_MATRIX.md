# Recovered task and delivery matrix

The original user's request referenced an exact assignment/rubric placeholder. The full school rubric was not in the supplied brief. These are the requirements recovered from the existing project's documented Year 10 digital multimodality task and the explicit build request.

| Requirement | Implementation | Verification |
|---|---|---|
| Clear title and persuasive purpose | Hero and brand, Chapter 00 | Static source audit + browser |
| Recognise bullying and cyberbullying | Chapter 01 definition, features, five forms | Source register + scenario testing |
| Prevention and safe bystander action | Chapter 02, four choices | Graph and feedback test |
| Australian evidence | eSafety survey and interactive chart/table | Static tests + chart interaction |
| Responsible international reference | UNICEF guide in resources | Link verification when network available |
| Reporting and support | Chapter 03 navigator, Chapter 04 directory | UI and official resource inspection |
| Linguistic mode | Extensive original copy, statistics, scenarios | Editorial review |
| Visual mode | Three original assets, three real photographs, chart and diagrams | Asset and screenshot audit |
| Spatial mode | Five-chapter narrative progression and WebGL network | Layout and graph review |
| Gestural mode | Recognition choices, chart tabs, bystander responses, support navigator and reflection | Browser tests |
| Aural mode | Opt-in speech, transcript and Web Audio feedback | Browser controls; physical output not guaranteed |
| Self-drawing diagrams | Support SVG line animation with reduced-motion alternative | Browser reduced-motion test |
| User reflection/comment wall | Local-only notes with deletion; fictional examples marked | DOM safety and persistence tests |
| Responsive accessibility | Focus, keyboard, reduced motion, fallback | Browser and manual audit |
| CSP image domain whitelist | `images.unsplash.com` and self | Source audit |
| Clean TypeScript and production build | `npm run typecheck`, `npm run build` | Run logs in QA report |
| Complete downloadable release | ZIP includes source, docs, workflow and assets | ZIP manifest check |
| Official teacher rubric | **NOT PROVIDED** | Cannot claim complete match to unseen criteria |

No public comment feed is included: it would require a backend, safeguarding policy and moderation. Local reflection meets the intent without exposing children to a publicly writable feed.
